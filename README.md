# Computación Avanzada 2026

Repositorio de trabajo individual para el curso. Este repositorio acompañará todo el proceso: perfil, ejercicios y proyecto final.

## Estructura

```text
.
├── README.md
├── AI_USAGE.md
├── about/
├── assets/
│   ├── images/
│   └── models/
├── exercise-01/
├── exercise-02/
├── project/
├── references/
└── .github/
    ├── copilot-instructions.md
    └── skills/
        └── course-site/
            └── SKILL.md
```

## Primer objetivo

1. Completar `about/README.md`.
2. Hacer un commit y push.
3. Usar `/course-site publish-about` en VS Code para generar el sitio.
4. Publicar con GitHub Pages.
5. Exportar un modelo 3D desde Rhino como `.glb` y guardarlo en `assets/models/`.
6. Usar `/course-site add-3d-model` para incorporarlo al sitio.

## Entregas

- Ejercicio 1: `exercise-01/`
- Ejercicio 2: `exercise-02/`
- Proyecto final: `project/`

> Publica solamente información que te acomode dejar visible en internet. No incluyas dirección, teléfono, RUN/RUT, contraseñas, tokens ni otra información sensible.
